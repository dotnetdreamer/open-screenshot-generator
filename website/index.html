Before you start

A few
useful answers

Read the documentation ↗
Is the editor really free?

Yes. All templates and design tools are free, with no watermark or export limit. The source is public under the MIT license. If you use an external AI provider, that provider may charge for its service

Do I need an account?

You can design, save locally, and export without an account. Sign in if you want cloud saving or live collaboration. You can also connect your own Google Drive or GitHub account

Where are my projects saved?

Local projects live in your browser storage. Clearing site data removes them, so save a project copy you want to keep. Cloud saving, sharing, connected accounts, store uploads, and AI use the services you choose

Can I change the design for each language?

Yes. Each language inherits the base layout. Translate the text, adjust fonts and sizing, or use different screenshots and backgrounds for one language. The editor offers 57 language options, with store availability depending on the language

Can I make preview videos?

Yes. Add a screen recording, adjust timing, animation, and audio, then export MP4. Use the App Store preview export for your screen recording, or export a styled video for a website or social post. Video export requires Chrome, Edge, or the desktop app

What does the desktop app add?

The same editor, plus direct uploads to App Store Connect and Google Play, Claude Code, local AI providers, and built in coding agent tools. Desktop apps are available for macOS, Windows, and Linux
