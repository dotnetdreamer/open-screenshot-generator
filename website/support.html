Support

For help with the editor or desktop app, email pak437337@live.com. You can also report a bug or suggest a feature in the GitHub issue tracker.

Email support

Reporting a problem

Include the app version, your macOS version or browser, what you expected to happen, and the steps that reproduce the problem. A screenshot or sample project can help if you are comfortable sharing it. Remove private information first, and keep API keys, login tokens, and store credentials out of reports.

GitHub issues are public. Use email for account questions, private project details, or privacy requests.

Using the editor

Start with a template or import your app screenshots. Add or edit artboards, device frames, text, and other elements, then export the finished screenshots or preview videos. The project README describes the available features.

Cost and accounts

Open Screenshot Generator is free. You can use the core editor and export your work without an account. Optional AI providers and connected services can have their own charges, subscriptions, or usage limits.

Accounts are optional for saving to your own Google Drive or GitHub, cloud storage, and community features. When you are signed in and cloud storage is available, cloud auto save is on by default. You can turn it off in Settings. Automatic sync to your own Drive or GitHub is off by default.

Finding and protecting your projects

The editor saves projects in local storage on the device where you work. Clearing browser or app data can remove those projects. Keep exported copies of work you need to preserve. If you saved a project to cloud storage or your own account, open that saved copy from the relevant destination.

Signing out does not delete cloud projects, community posts, or files saved to your own accounts.

AI help

AI features are optional. If a provider rejects a request, check the provider account, API key, model, and any usage limits. Local AI needs a running local provider and a model that supports the content you send. Cloud AI and provider website sessions send content to the selected provider under its privacy policy.

Privacy and account deletion

Read the privacy policy for details about local data, cloud storage, community posts, collaboration, AI, and website analytics.

To request deletion of your cloud or community account and associated content, email pak437337@live.com with the provider and account you used. We may need information to verify that the account is yours. You can delete individual cloud projects and your own community posts in the app.

Files stored in Google Drive or GitHub, AI conversations held by a provider, and content uploaded to an app store are managed through those services. Removing local editor data does not remove those copies. Contact support for details about technical logs, backups, or a deletion request.
